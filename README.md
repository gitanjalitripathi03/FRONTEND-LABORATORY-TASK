## 🌷 About This Repository

This repository is a home for my frontend laboratory tasks. Each project explores a different part of web development—from creating personal pages and structured timetables to using selectors, lists, and interactive effects.

The goal was not only to make pages that work, but to make them feel pleasant to use. Every exercise uses simple web technologies while focusing on clear layouts, thoughtful colour choices, and small interactive details.

> 💡 **Learning by building:** Each file represents a step in my journey from basic HTML structure to styled, responsive webpages.

## 🎨 Project Highlights

### 👩‍💻 Personal Portfolio

The portfolio is a simple digital introduction designed for a Computer Science student. It uses a soft pink theme and divides content into easy-to-read sections.

**Highlights:**

- Smooth in-page navigation links
- Introductory home section with a call-to-action button
- Personal About Me and Education sections
- Dedicated Skills area for HTML, CSS, Java, DSA, SQL, and GitHub
- Clean project cards for showcasing work
- Contact links for email, LinkedIn, and GitHub

### 🗓️ Academic Timetable

The timetable turns a large amount of academic information into a clear visual schedule. It uses table features such as merged cells and a responsive CSS layout to keep the information organised.

**Highlights:**

- Weekly schedule from Monday to Saturday
- University, programme, semester, and session information
- Merged table cells for practical classes and longer sessions
- Distinct visual treatment for headers, times, days, and subjects
- Hover effects for subjects and schedule rows
- Responsive styling for smaller screens

### 🤝 About Us Page

This page introduces a student group in a friendly, simple format. It is also a practical exploration of HTML elements and common CSS selector types.

**Highlights:**

- Semantic `header`, `main`, `section`, and `footer` elements
- “Who We Are” introduction section
- Ordered list of favourite movies
- Unordered list of favourite cities
- Custom list markers and item hover effects
- Styled call-to-action contact link
